# Паловбек

**166 700 нейронов. Шесть лапок. Один казан.**

Муха в тюбетейке готовит узбекский плов, а рядом видно активность симулируемых нейронов. Она режет морковь, мешает зирвак, закладывает рис, закрывает казан и терпеливо ждёт. Иногда потирает лапки и шутит.

**[Открыть кухню → plov.mrz.sh](https://plov.mrz.sh)** · [English README](../README.md)

## Как это работает

В браузере работает упрощённая модель спайковых нейронов на основе коннектома MaleCNS: **166 700 нейронов и 25 582 938 взвешенных связей**. Движок адаптирован из проекта Xenova.

**Порядок действий задаёт рецепт. Измеренная активность модели влияет на размер порций и небольшие паузы.** Нейросеть не обучалась готовить. Анимация тела, кухонная физика, связь сенсорных сигналов с нейронами и реплики Паловбека написаны разработчиком. Реплики — юмор персонажа, а не прочитанные мысли мухи.

Есть четыре рецепта, 3D-визуализация активности, журнал приготовления в JSON, русский и английский интерфейс. Скриптовая демонстрация доступна отдельно и подписана соответствующим образом.

## Запуск на своём компьютере

Нужны Node.js 22.18+, npm и современный браузер с WebGL2. Для модели предпочтителен WebGPU; предусмотрен JavaScript CPU fallback. Требуется несколько сотен мегабайт рабочей памяти. Производительность телефона зависит от устройства.

```sh
git clone https://github.com/meerzulee/palovbek.git
cd palovbek
npm ci
npm run assets:prepare
npm run dev
```

Откройте **http://localhost:5173** и нажмите **«Загрузить веса · 79 МБ»**. После инициализации Паловбек начнёт готовить. Файлы проверяются по SHA-256 и сохраняются в кэше браузера. На следующем визите создаётся новая сессия; повторная полная загрузка обычно не нужна.

Python-сервер, API-ключ и обучение модели для браузерной версии не требуются. Кухня работает, пока открыта вкладка; браузер может приостановить её в фоне.

## Проверки и публикация

```sh
npm test
npm run build
npm run check:static
npx playwright install chromium
npm run test:e2e
```

Полный тест готовит плов на реальной симуляции графа, проверяет порядок, порции, загрузки, паузу и журнал. На протестированном M5 приготовление свадебного плова занимает около шести минут.

Для Cloudflare сначала измените имя Worker и домен в `wrangler.jsonc` на свои. Затем выполните `npx wrangler login` и `npm run deploy`. Cloudflare раздаёт файлы, а вычисления идут на устройстве посетителя. Общего мозга, работающего без зрителей 24/7, у браузерной версии нет.
